# Lab10
ARTI308: Machine Learning - Support Vector Machines (SVM)This repository contains two Jupyter Notebooks designed to introduce and apply the Support Vector Machine (SVM) algorithm for classification tasks. The notebooks cover data preprocessing, model training, performance evaluation, and hyperparameter tuning.📁 Notebooks Overview1. SVM Lab: Breast Cancer PredictionGoal: Implement a binary classifier to diagnose breast cancer based on tumor characteristics.  Dataset: Scikit-learn's built-in Breast Cancer Wisconsin (Diagnostic) dataset, which includes 30 numeric features (e.g., radius, texture, area) and two classes: Malignant and Benign.  Key Workflow:Data Preparation: Converting dictionary-style data into a Pandas DataFrame.  Initial Training: Training a basic SVC model.  Performance Bottleneck: The initial model may suffer from poor parameter selection, often leading to biased classification.  Grid Search: Utilizing GridSearchCV to find the optimal values for C (regularization) and gamma (kernel coefficient).  2. SVM Assignment: Iris Species ClassificationGoal: Apply SVM to a multi-class problem using the famous Fisher's Iris dataset.  Dataset: 150 samples across three species: Iris Setosa, Iris Versicolor, and Iris Virginica. Features include sepal/petal length and width.  Key Workflow:Exploratory Data Analysis (EDA): Visualizing species differences through images and seaborn plots.  Implementation: Loading data via seaborn and preparing it for supervised learning.  🛠️ Technical Concepts CoveredSupport Vector Machines (SVM)A supervised learning algorithm used for classification and regression. It works by finding the "separating plane" (hyperplane) that maximizes the margin between different classes.  Hyperparameter Tuning (Grid Search)The notebooks emphasize that SVM performance is highly dependent on parameters:C: Controls the trade-off between achieving a low error on the training data and maximizing the margin.gamma: Defines how far the influence of a single training example reaches (high gamma means only close points are considered).  GridSearchCV: A "meta-estimator" that automates the process of trying multiple combinations of these parameters to find the best-performing model.  Evaluation MetricsThe notebooks use standard classification tools from sklearn.metrics:  Confusion Matrix: A summary of prediction results on a classification problem.Classification Report: Provides Precision, Recall, and F1-score to give a more nuanced view of model accuracy.  🚀 Libraries UsedPandas & NumPy: Data manipulation and matrix operations.  Matplotlib & Seaborn: Data visualization.  Scikit-learn: Model training (SVC), data splitting (train_test_split), and tuning (GridSearchCV).
